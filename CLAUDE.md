# Claude entry point

Read and follow the shared repository instructions in `AGENTS.md`.

Before starting or resuming work, read `docs/handover.md` and its linked latest work-item note. Check the actual branch, HEAD and working tree before trusting recorded state.

After every work item, update the same shared handover files used by Codex, following the checklist in `AGENTS.md` and the template in `docs/handovers/TEMPLATE.md`. Preserve other contributors' work and coordinate separate branches/worktrees when working concurrently.

Do not duplicate status here. The shared handover is the entry point for current status, validation, limitations and next steps.
